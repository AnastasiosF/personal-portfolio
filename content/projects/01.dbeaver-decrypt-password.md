## What it does

DBeaver keeps saved connection credentials in `credentials-config.json`, encrypted with a
fixed AES key that ships with the application. This tool reads that file, decrypts it, and
prints the connection names with their usernames and passwords, so you can recover access to a
database you configured months ago and forgot the password for.

## How it works

The file is AES-128-CBC encrypted with a well-known key and the first 16 bytes used as the IV.
The core of the program is only a few lines:

```java
Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
cipher.init(Cipher.DECRYPT_MODE, new SecretKeySpec(KEY, "AES"), new IvParameterSpec(iv));
byte[] json = cipher.doFinal(payload);
System.out.println(new String(json, StandardCharsets.UTF_8));
```

Everything else is locating the file for the current OS and pretty-printing the JSON.
