## What it does

A minimal Spring Boot application that authenticates against Gmail over SMTP and sends two
emails on startup: one plain text, one HTML. It exists to be copied into other projects that
need transactional email without a third-party provider.

## Configuration

```yaml
spring:
  mail:
    host: smtp.gmail.com
    port: 587
    username: ${MAIL_USER}
    password: ${MAIL_APP_PASSWORD}
    properties:
      mail.smtp.auth: true
      mail.smtp.starttls.enable: true
```

Gmail requires an app password when two-factor authentication is on, which is the part most
people get stuck on. The README walks through generating one.
